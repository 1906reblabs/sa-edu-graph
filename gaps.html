This cycle's coverage gap report

An honest account of where the index is thin, so nobody mistakes an empty search result for "this doesn't exist."

Closed this cycle

  • Official-language Grade 1–2 graded readers and Big Books. Previously only English, Afrikaans, isiZulu and isiXhosa were indexed. We found the DBE's own Graded Readers and Big Book HL index page lists all 11 official languages, and added Grade 1 ("Animal Sports Day") and Grade 2 ("A Dog's Life") readers, plus Grade R Big Book 1, in isiNdebele, Sepedi, Sesotho, Setswana, siSwati, Tshivenda and Xitsonga — 23 new trust-A records.

Known gaps as of this cycle

  • Grade 3+ graded readers are still not indexed in any language. The DBE index page we used this cycle does list a Grade 3 series (confirmed present, not yet transcribed) — queued as next cycle's top priority.
  • Grade skew. Coverage is heavily weighted toward Grade 12 / FET past papers and Olympiad material. Foundation and Intermediate Phase coverage is improving (workbooks, graded readers, Big Books) but is still thinner than FET.
  • IEB coverage is weak. Re-checked this cycle: the IEB's own site now routes its official past-paper access through the "IEB/Xhuma-Ed Examination Revision Portal," which is a login-gated app, not an open archive. Our only current IEB entries remain a third-party rehost (trust level C) covering five subjects. No trust-A source found.
  • Cambridge IGCSE is index-level, not paper-level. Current IGCSE listings link to a subject's full past-paper archive page rather than a specific session's question paper and mark scheme. Coverage is limited to twelve subjects; SA-relevant codes (Afrikaans, isiZulu, Setswana) are included, but many others are not yet indexed.
  • Three records remain on the needs-review list (unchanged this cycle — see below) pending a human check.

Next cycle's discovery queue

  1. P1. Grade 3 DBE graded readers, all 11 official languages — site:education.gov.za "Graded Readers and Big Book HL" Grade 3, plus direct transcription of the Grade 3 section already located on the index page this cycle.
  2. P1. DBE Big Books 2–8 (all languages) — same source page, only Book 1 indexed so far per language.
  3. P2. Grade 4–9 graded readers / reading books in official languages other than English/Afrikaans — not yet located; search DBE Intermediate Phase reader isiZulu OR Sesotho OR Xitsonga site:education.gov.za.
  4. P4. Foundation Phase teacher guides accompanying the Rainbow Workbooks — check the Workbooks index page's teacher-guide links, not yet harvested.
  5. P7. Trust-A IEB or Cambridge alternative — re-check periodically; no change found this cycle or last.
If you know a trust-A source we're missing — especially for IEB or Cambridge — tell us.
